## ✦ 𝐀𝐁𝐎𝐔𝐓 𝐌𝐄
> **FROM ADOBE FRUSTRATION TO OPEN SOURCE SOLUTIONS.**

I didn't start coding just for the sake of it. I started because I was tired of the limitations, bugs, and bloatware found in major creative suites (looking at you, **Adobe** 😒). I realized that if I wanted tools that actually worked for me, I had to build them myself.

Now, my philosophy is simple:
* **🚫 Anti-Data Hoarding:** I dislike the fact that big tech owns our digital lives.
* **🔒 Local First:** Cloud is an *option*, not a requirement.
