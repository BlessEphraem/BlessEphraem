### 📜 𝐒𝐂𝐑𝐈𝐏𝐓𝐒
* [![AHK](https://img.shields.io/badge/📜_AHK-2EA043?style=for-the-badge)](https://github.com/BlessEphraem/AHK) : AutoHotKey Script that I use every-day.
